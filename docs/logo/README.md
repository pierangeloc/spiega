# Logo candidates

```bash
node tools/logo.js     # regenerate, then open index.html
```

Six files: three marks, each on paper and on ink. Nothing here is chosen yet.

| mark | the idea | honest read |
|---|---|---|
| `board-and-stroke` | a board with a stroke on it | closest to the brief. The frame says "board", the orange says "written". Survives 16px as a filled lozenge |
| `stroke-to-box` | a free line that becomes a drawn box | closest to what the tool *does* — talking turning into structure. Weakest at 16px, where the line is one pixel |
| `written-s` | the initial, written not set | the strongest mark and the weakest message: it says "a confident hand" but nothing about boards |

They are generated by [`tools/logo.js`](../../tools/logo.js) from
[`src/render/ink.js`](../../src/render/ink.js) — the same wobble, seeds and
palette the board itself draws with, so the hand-drawn quality is the real one
rather than an imitation of it. Change the geometry in that file, not the SVGs.

## What was tried and dropped

- **two boxes and a line** — reads as "oo" at 16px, and both boxes disappear
  against a dark ground.
- **a half-drawn box** — an ambiguous hook that said neither board nor writing.
- **a pen**, twice: once small, once deliberately large. It never read as a
  pen. At the sizes that matter it is a dark speck beside a dark stroke, or a
  blob in a corner. This is the same failure as the hand in issue #2, and the
  same conclusion — a 16px mark cannot carry a recognisable object. The
  writing has to be implied by the stroke, not by the thing holding it.

The 16px column is the test. A mark that needs 48px is an illustration.
